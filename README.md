# Aliaksandr Yasiukaitsis

I build local-first tools for AI agents, macOS, and the boring parts of software that need to be reliable.

Most of my projects start from the same question: what can run on the user's machine, with an explicit boundary, no account, and a result that can be checked?

## How I work

- Local first. A network call is a decision, not a default.
- Read-only until an action is explicitly authorized.
- Measure the claim, or label it as an assumption.
- Prefer a small tool with tests and a demo over a large promise.
