# Aliaksandr Yasiukaitsis

I build small tools that run on your own computer: for AI agents, macOS, and the boring parts of software that need to be reliable.

Most of my projects start with the same question: what can stay on the machine, work without an account, and give a result you can check?

## How I work

- Local first. A network call is a decision, not a default.
- Read-only until an action is explicitly authorized.
- Measure the claim, or label it as an assumption.
- Prefer a small tool with tests and a demo over a large promise.
